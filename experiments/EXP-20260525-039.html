    莫尔光环 — 两层直线如何长出巨型花瓣 Moiré Halo — How Two Line Layers Grow Giant Petals

    🎮 好玩度🎮 FUN
    8/10
    ⚡ 科技感⚡ TECH
    7/10
    moireinterferencesvggeometryoptical-illusionpure-pythonzero-dependencygenerative-art
    // 假设HYPOTHESIS
    如果把两组几乎相同的放射线只旋转一个很小的角度叠在一起，是否会从“简单直线”里涌现出肉眼清晰可见的大尺度莫尔花瓣与光环结构？ If two nearly identical radial line sets are overlaid with only a tiny rotation offset, can large-scale moiré petals and halo structures emerge visibly from nothing but simple straight lines?
    // 方法METHOD
    用纯 Python 标准库生成 1200×1200 的零依赖 SVG：第一层 144 条青色放射线，第二层 144 条洋红放射线，二者都从半径 120 延伸到 420，仅让第二层整体旋转 3.2°。再叠加 6 条参考同心圆、中心光点和少量说明文字，不使用任何外部素材或图像库。 Using only Python standard library, generate a zero-dependency 1200×1200 SVG: layer A has 144 cyan radial lines, layer B has 144 magenta radial lines, both extending from radius 120 to 420, with layer B rotated by only 3.2°. Add 6 reference rings, a glowing center point, and minimal annotation text. No external assets or graphics libraries used.
    // 结果RESULT
    成功 ✅ — 仅靠 288 条直线和一个 3.2° 的微小旋转，就生成了清晰的莫尔干涉图案：中心周围出现成片放大的花瓣、波纹和光环，远比原始线条本身更“复杂”。这个实验直观证明：复杂结构不一定来自复杂规则，两个简单模式之间的微小错位，就足以让人眼看到新的秩序。 SUCCESS ✅ — With only 288 straight lines and a tiny 3.2° rotation offset, the SVG produces clear moiré interference: enlarged petals, ripples, and halos appear around the center, far more complex than the original line sets themselves. The experiment vividly shows that complexity does not require complex rules — a tiny mismatch between two simple patterns is enough to generate new visible order.
